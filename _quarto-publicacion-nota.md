# Seguridad editorial

`privado-docente/` se entrega en un ZIP independiente para uso local de la instructora; no se incluye en el ZIP del sitio. **Debe excluirse de un repositorio GitHub público**, incluso si no se enlaza desde la navegación; Quarto no impide que Git publique archivos fuente ajenos al sitio.

Para un despliegue público: mover primero `privado-docente/` a una carpeta fuera de la raíz del repositorio. Publicar únicamente `index.qmd`, `contenido/`, `recursos/`, `descargas/`, `_quarto.yml` y documentación pública revisada.
